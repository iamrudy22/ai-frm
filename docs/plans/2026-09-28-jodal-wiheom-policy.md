# 조달위험 인식 지수 (4단계) — 정책

**작성일**: 2026-09-28
**대상**: `/aifrm` 통합 대시보드, 다섯 번째 지표
**원본**: 자금기획팀 기준(2026-09-28 전달). 지금까지는 담당자가 금융투자협회 채권정보센터 화면에서 값을 옮겨 적었다.

## 0. 한 줄 요약

전월 마지막 평가일의 **공사채 AAA 1년 금리 − 국고채 1년 금리**(3사 평균)로 공사채 조달 비용이
무위험 금리보다 얼마나 비싼지를 보고, 0.24 / 0.52 / 0.79 %p 구간으로 **정상·주의·경고·위기**를 판정한다.
값이 클수록 위험하다.

| 용어 | 정의 |
|---|---|
| 판단월 | 최신 회차의 달. 대금 회수 위험의 판단월과 같다 |
| 관측월 | 판단월 − 1개월. 이 달의 마지막 평가일 금리를 쓴다 |
| 평가일 | 채권평가사가 시가평가 수익률을 낸 날. 주말·공휴일은 없다(연말 휴장일 12/31은 있다) |
| 3사 평균 | 나이스피앤아이·한국자산평가·KIS자산평가 세 곳의 평균. 채권정보센터가 낸 값 그대로 쓴다 |
| 금리 차이 | 공사채 AAA 3사 평균 − 국고채 3사 평균, %p |

코드 식별자는 `funding-risk`다. `procurement`는 구매 조달로 읽혀서 쓰지 않는다.

## 1. 산식

```
금리 차이 = 특수채/공사채 및 공단채/AAA (1년) − 국채/국고채권/양곡,외평,재정 (1년)
            둘 다 관측월 마지막 평가일의 3사 평균(%)
```

**예**: 2026/08 판단 → 2026/07/31 평가일 → 3.674 − 3.393 = **0.281%p → 주의**.

금리는 소수 셋째 자리까지 온다. 뺄셈은 **1/1000 %p 정수**로 한다(3674 − 3393 = 281).
부동소수로 빼면 3.243 − 3.003 = 0.23999…가 되어 0.24 경계를 넘지 못하고 정상으로 잘못 판정된다.
정수 차이를 1000으로 나눈 값은 구간표의 0.24·0.52·0.79와 같은 부동소수가 되므로 경계가 정확하다.

## 2. 판정 구간

| 금리 차이 | 판정 |
|---|---|
| 0.24%p 미만 | 정상 (G) |
| 0.24%p 이상 0.52%p 미만 | 주의 (Y) |
| 0.52%p 이상 0.79%p 미만 | 경고 (O) |
| 0.79%p 이상 | 위기 (R) |

경계값은 위 단계다(0.24는 주의). 음수(공사채가 국고채보다 싸다)는 정상이다.
등급별 한 줄 코멘트는 원문이 없어 임시 문구다. 받으면 `policy.ts`의 표만 바꾼다.

## 3. 판단월과 조회일 (2026-09-28 확정)

- **판단월 = 최신 회차의 달.** 회차를 올리지 않고 부르면 오늘이 속한 달이다.
- **조회일 = 관측월(판단월 − 1)의 마지막 평가일.** 8월 판단이면 7/31이다.
- **말일이 평가일이 아니면 그 전 평가일을 쓴다.** 5/31(일)이면 5/29(금). 관측월 1일~말일을
  한 번에 조회해 가장 늦은 평가일을 고른다 — 휴일 달력을 따로 두지 않는다. 화면에 실제로 쓴 평가일을 밝힌다.
- 마지막 평가일의 3사 평균이 비어 있으면 **산출불가**다. 그 전 평가일로 더 내려가지 않는다.
- 관측월이 아직 끝나지 않았으면(관측월 ≥ 이번 달) 조회하지 않고 산출불가다. 달 중간 값을 말일 값처럼 쓰지 않는다.

## 4. 출처 — 금융투자협회 채권정보센터

화면: www.kofiabond.or.kr → 시가평가 → 채권시가평가수익률 → **기간별**.
화면이 부르는 내부 XML 서비스를 서버에서 직접 부른다. 공개 API가 아니다. 인증키·쿠키·세션은 필요 없다.

```
POST https://www.kofiabond.or.kr/proframeWeb/XMLSERVICES/
Content-Type: application/x-www-form-urlencoded; charset=UTF-8   ← 본문은 XML이지만 사이트 JS가 이 헤더로 보낸다
```

| 요청 필드 | 값 | 뜻 |
|---|---|---|
| `pfmAppName` / `pfmSvcName` / `pfmFnName` | `BIS-KOFIABOND` / `BISBndSrtPrcSrchSO` / `selectTrm` | 기간별 조회 |
| `val31`, `val32` | `3030110`, `0100` | 특수채/공사채 및 공단채/AAA, 1년 |
| `val33`, `val34` | `1010000`, `0100` | 국채/국고채권/양곡,외평,재정, 1년 |
| `creditEstOrgCd` | `A20000` | 평가사 평균('23.1.9~) |
| `val1`~`val3` | `A10002`, `A10003`, `A10004` | 나이스피앤아이, 한국자산평가, KIS자산평가 (`val4`·`val5`는 빈칸) |
| `standardDt1`, `standardDt2` | `YYYYMMDD` | 조회 시작일·종료일 |

응답은 평가일마다 `<BISBndSrtPrcTrmDTO>` 한 행이다. 채권종류 하나에 7칸
(나이스·한국·KIS·에프앤·이지·N사 평균·금투협)이므로:

| 칸 | 공사채 AAA | 국고채 |
|---|---|---|
| 나이스피앤아이 | `val1` | `val8` |
| 한국자산평가 | `val2` | `val9` |
| KIS자산평가 | `val3` | `val10` |
| **3사 평균** | **`val6`** | **`val13`** |

### 확인된 응답의 성질 (2026-09-28 실제 호출)

| 성질 | 대응 |
|---|---|
| 말일이 주말이면 그 날짜 조회는 0건 (2026/05/31, 2026/01/31) | 관측월 전체를 조회해 가장 늦은 평가일을 쓴다 (§3) |
| 3사 평균은 셋째 자리 아래를 **버린다** — 5/27 공사채 (3.385+3.389+3.389)/3 = 3.38767 → 3.387 | 직접 평균 내지 않고 `val6`·`val13`을 쓴다. 화면·엑셀과 같은 값이 된다 |
| 행은 날짜 내림차순 | 순서에 기대지 않고 가장 늦은 날짜를 고른다 |
| 2023/01/09 전은 행은 오지만 값이 빈칸(3사 평균 서비스 전) | 빈칸은 값 없음. 0으로 읽지 않는다 → 산출불가 |
| 오류도 HTTP 200. 헤더에 `pfmResponseCode`·`pfmResponseBasc`가 온다 | 코드가 있으면 조회 실패 |
| CORS 헤더 없음 (OPTIONS 405) | 브라우저에서 부를 수 없다. 라우트(서버)에서만 부른다 |

### 위험

공개 API가 아니어서 사이트 개편 때 깨질 수 있다. 녹화한 응답 fixture로 번역을 검증하고,
실제 사이트를 부르는 확인 테스트(`KOFIA_LIVE=1`)로 모양이 바뀌었는지 볼 수 있게 한다.
깨지면 산출불가와 조회 실패 사유가 보인다. 호출은 산출할 때 한 번뿐이다.

## 5. 산출불가

| 경우 | 사유 |
|---|---|
| 관측월이 끝나지 않음 | `아직 YYYY/MM 말이 지나지 않았습니다.` |
| 조회 실패(네트워크, 오류 응답, 모양 변경) | `채권정보센터 조회 실패: …` |
| 관측월에 평가일이 없음 | `YYYY/MM에 평가일이 없습니다.` |
| 마지막 평가일의 3사 평균이 빈칸 | `YYYY/MM/DD 평가일의 공사채 AAA·국고채 3사 평균이 비어 있습니다.` |
