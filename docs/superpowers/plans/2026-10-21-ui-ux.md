# AI-FRM UI/UX 개선 계획과 진행 기록

시작 기준: `b9b0768` · 작업 브랜치: `codex/aifrm-ui-ux`

## 변경 금지 경계

- **추가 확정: 리포트 템플릿도 변경하지 않는다.** UI 개선 전 `b9b0768`의 본문·배치·여백·색상·차트·단위 표기·인쇄 스타일을 보존한다. 아래 과거 기록 중 보고서 표현 변경은 마지막 복원 단계에서 취소했다. 보고서 용지 바깥의 화면 조작 도구는 유지한다.
- 계산식, 가중치, 임계값, 등급, 기준월 정책, 원천 계열, 정밀도는 변경하지 않는다.
- `src/domain`, `src/application`, 서버 API·인프라·엑셀 어댑터는 수정하지 않는다.
- 기존 report-model의 산출값·반올림·자료 해석도 보존한다. 화면 표현과 UI 요청/준비 상태만 개선한다.
- 실제 비공개 자료 대신 합성 엑셀로 QA한다. 비밀값·원본 재무정보는 기록하지 않는다.
- Astryx 0.5.4가 이미 설치되어 있다. 설치된 CLI 문서로 컴포넌트를 확인하며 기존 reset/core/theme 연결을 유지한다.

## 단계와 완료 기준

아래 1~7은 최초 실행 계획이며, 보고서 템플릿 변경에 해당하는 1·3·5단계 일부는 최신 사용자 지시에 따라 복원했다. 앞으로는 위 변경 금지 경계가 우선한다.

1. **값과 단위**: 보고서의 회수율·Gap 큰 값에 배 단위를 붙인다. 비적용·결측에는 단위를 붙이지 않는다. T/F 의미는 기존 상태 라벨을 유지하며 가까이 배치한다.
2. **외부 조회와 복구**: 건설경기 이전 결과/조회 중 상태를 요약에도 반영한다. 실패 후 같은 요청 재시도와 기본값 복귀를 제공한다. 요청 경합에서 마지막 선택만 표시한다.
3. **모바일 차트**: 화면용 읽기 가능한 최소 차트 폭과 자체 스크롤, 월별 값 표를 제공한다. 인쇄 3/4쪽과 기존 값·결측 연결 정책은 유지한다.
4. **파일 준비 안내**: 업로드를 첫 행동으로 두고 회차 예시와 단계 안내를 제공한다. 실제 선택 후 필요 회차 표가 최종 기준이다.
5. **접근성**: 상태 글자·차트 선 대비, 보고서 진입/복귀 포커스, 차트 값 대체 정보를 검증한다.
6. **새 파일 오류 복구**: 새 입력 준비와 현재 결과를 분리하여 실패 후 이전 결과로 돌아올 수 있게 한다. 파일과 결과 소속을 혼동시키지 않는다.
7. **탐색과 저장**: 지표 이동과 보고서 고정 작업 도구를 제공한다. 조회 상태·인쇄 쪽수를 안내하고 화면용 제어는 인쇄에서 제외한다.

각 단계는 동작 테스트 RED→GREEN(단순 문구·색상은 실제 화면 검증) → 관련 검사/전체 테스트 → 독립 검토 → 화면 QA → 커밋 → 이 문서의 컨텍스트 갱신 순서로 진행한다. 마지막에는 타입·전체 테스트·린트·빌드와 도메인 경계의 무변경을 확인한다. 푸시·원격 머지는 수행하지 않는다.

## 사전 검토 / 결정

- 보고서 값과 대시보드 값은 단위 차이이며 계산 오류가 아니다. 보고서의 기존 배수 및 정밀도를 그대로 유지한다.
- 적정시재 상태 라벨은 이미 제공된다. 새 위험 등급을 만들거나 T/F를 큰 긴 문장으로 교체하지 않는다.
- 조달위험에는 이미 재시도와 요청 식별이 있다. 건설경기 복구에 집중한다.
- 건설경기 실패 DTO에는 선택 가능 월 정보가 없다. 실패 시 월 범위를 추측 생성하지 않고 같은 요청 재시도·기본값 복귀로 복구한다. 정책 응답이 있으면 기존 선택 정보를 사용한다.
- 구조는 960px 단일 작업 영역을 유지한다. 입력과 자료 상태는 행/표, 보고서는 문서형 레이아웃을 사용한다.
